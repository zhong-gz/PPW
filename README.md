# PPW

All code are run on Python 3.11.5

Run 'run_all.py', the code will run all experiments. The result can be found in 'result' folders of each dataset folders, such as 'SyntheticDatasets/result'.

To evaluate the performance on the large-scale high-dimensional dataset, please run 'SyntheticDatasetsLarge/linear_regression.py'. The result can be found in 'SyntheticDatasetsLarge/result' folders.
